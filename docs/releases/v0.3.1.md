# Game Shift v0.3.1

计划发布日期：2026-10-26

版本状态：Beta

发布渠道：GitHub Releases

Game Shift v0.3.1 新增游玩会话记录和累计游玩时长展示，并修复跨天后“今天 / 昨天”日期标签未及时更新的问题。

## 主要更新

### 累计游玩时长

- 游戏列表新增“累计时长”列，包含本次运行中已经确认的游玩进度。
- 游戏退出后保存本次时长，并计入累计值。
- 不足一分钟显示整数秒数，较长时长按分钟或小时显示；没有时长、零时长及不足一秒时显示“—”。
- 累计时长的悬停说明展示统计范围；普通卡片和快捷卡片保留原有日期展示，不显示时长。

### 游玩记录保存

- 自动记录通过 Game Shift 启动的游戏会话，定期保存进度。
- 游戏退出、正常关闭 Game Shift 或安装应用更新时保存已确认的时长。
- Game Shift 异常结束后，下次启动保留最后已保存的进度，不补算离线时间。
- 保留已有游戏库、收藏、启动次数和最近游玩时间，不推算升级前的历史时长。

### 修复

- 修复跨天后“今天 / 昨天”日期标签未及时更新的问题。切回窗口、恢复页面可见或重新进入页面时，列表和卡片的正文及悬停日期同步刷新。

## 统计范围与限制

- 只统计通过 Game Shift 直接启动、且管理器运行期间能够确认的进程时长。
- 最小化窗口或切换页面不影响后台计时。
- 关闭 Game Shift 不会关闭游戏，但会停止跟踪和计时；重新打开后不会接管旧进程，也不补算关闭期间的时长。
- 从外部启动的游戏，以及启动器退出后继续运行的子进程，不在统计范围内。
- 异常结束时，尚未保存的尾段可能丢失；进程状态暂时无法确认时，不推算未知时长。
- 本版只展示累计时长，暂不展示单次时长、游玩会话列表或游戏详情页，也不提供关闭游戏进程的操作。

## 升级说明

- v0.2.1 及以上版本可在本版发布后通过应用内更新安装 v0.3.1。
- v0.2.0 及更早版本需要从 GitHub Releases 手动下载安装。
- 覆盖安装和应用内更新保留现有游戏库数据；如需备份，可在设置页查看数据库文件位置。

## 安全说明

- 应用内更新使用 Tauri Updater 签名校验；Updater 签名不等同于 Windows Authenticode 代码签名。
- 当前安装包未购买商业代码签名证书，Windows SmartScreen 仍可能显示“未知发布者”提示。
- 请核对 Release 提供的 SHA-256 校验文件，并从官方渠道下载安装包。

## 系统要求

- Windows 10 / 11。
- x64 处理器与操作系统。
- Microsoft Edge WebView2 Runtime。
