# Game Shift v0.2.3

发布日期：2026-08-21

版本状态：Beta

发布渠道：GitHub Releases

Game Shift v0.2.3 重点升级前端构建链，并重构应用的共享交互组件，提高界面行为的一致性和后续可维护性。

## 主要更新

- 升级 Vue、Vite 和 TypeScript 等前端构建依赖。
- 引入 Reka UI，统一弹窗、下拉选择、开关和提示浮层的交互基础。
- 统一共享组件的禁用、加载、焦点和键盘交互状态。
- 补充 Vitest 组件测试，覆盖按钮、开关、弹窗、下拉选择和提示浮层的关键交互。
- 完善项目校验流程，将前端组件测试纳入发布前完整验证。

## 升级说明

- v0.2.1 和 v0.2.2 用户可以在应用内检查并安装 v0.2.3 更新。
- v0.2.0 及更早版本需要从 GitHub Releases 手动下载安装。
- 覆盖安装和应用内更新不会删除现有游戏库数据。

## 下载

请从项目的 [GitHub Releases](https://github.com/mpasdi/game-shift/releases) 下载：

```text
Game Shift_0.2.3_x64-setup.exe
```

## 安全说明

- 更新安装包使用 Tauri Updater 签名校验，应用只内置公钥，不包含签名私钥。
- Updater 签名不等同于 Windows Authenticode 代码签名。
- 当前安装包未购买商业代码签名证书，Windows SmartScreen 仍可能显示“未知发布者”提示。

## 系统要求

- Windows 10 / 11。
- x64 处理器与操作系统。
- Microsoft Edge WebView2 Runtime。
