# Game Shift v0.1.0

发布日期：2026-07-13  
版本状态：Beta  
发布渠道：GitHub Releases

Game Shift v0.1.0 是首个公开可用版本，目标是提供一个简洁、轻量、数据保存在本地的 Windows 游戏库与启动器。

## 主要功能

- 手动选择 `.exe` 添加本地游戏。
- 扫描游戏目录并批量导入候选程序。
- 自动提取游戏图标并发现游戏目录中的本地封面。
- 使用列表或网格视图浏览游戏库。
- 按游戏名称或启动程序文件名搜索。
- 收藏游戏，并按最近收藏时间排序。
- 展示最近游玩记录、最后启动时间和启动次数。
- 支持工作目录和自定义启动参数。
- 编辑或移除游戏记录；移除操作不会删除本地游戏文件。
- 使用 SQLite 在本地保存游戏库。
- 设置页展示应用版本、应用数据目录和数据库位置。

## 系统要求

- Windows 10 / 11。
- x64 处理器与操作系统。
- Microsoft Edge WebView2 Runtime。

## 下载

请从项目的 [GitHub Releases](https://github.com/mpasdi/game-shift/releases) 下载：

```text
Game Shift_0.1.0_x64-setup.exe
```

发布页面同时提供对应的 SHA-256 校验文件。

## 安全说明

当前版本未购买商业 Windows 代码签名证书，安装时可能出现“未知发布者”或 Windows SmartScreen 提示。

安装前请确认：

1. 安装包来自项目官方 GitHub Releases。
2. 文件名和版本号与发布页面一致。
3. 本地计算的 SHA-256 与发布页面提供的校验文件一致。

```powershell
Get-FileHash -LiteralPath '.\Game Shift_0.1.0_x64-setup.exe' -Algorithm SHA256
```

## 数据说明

- 游戏库数据保存在本地 SQLite 数据库中，不会上传到服务器。
- 设置页会显示应用数据目录和数据库文件位置。
- 从 Game Shift 移除游戏只删除数据库记录，不删除磁盘中的游戏文件。
- 卸载或清理应用数据前，如需保留游戏库，请先备份数据库文件。

## 已知限制

- 当前仅提供 Windows x64 安装包。
- 安装包暂未进行商业 Windows 代码签名。
- 暂不跟踪游戏进程运行状态。
- 暂不统计单次或累计游玩时长。
- 暂不提供自动更新。
- 分类与标签功能尚未开放。
- 联网封面搜索尚未开放。
