# Game Shift v0.2.2

发布日期：2026-08-04

版本状态：Beta

发布渠道：GitHub Releases

Game Shift v0.2.2 重点优化目录扫描与候选确认体验。新版会结合目录结构、程序信息和游戏运行时特征对 `.exe` 候选进行排序和分组，帮助用户更快找到可能的游戏入口，同时保留不确定项目供手动选择。

## 主要更新

- 为 `.exe` 候选增加综合评分，结合目录结构、程序名称、PE 版本信息、文件大小和游戏运行时特征判断推荐顺序。
- 扫描结果区分“推荐游戏”“其他可执行文件”和“已存在”，仅默认勾选推荐且尚未导入的项目。
- 保留无法确定的可执行文件供用户展开和手动选择，避免因过滤规则过严而遗漏游戏入口。
- 补充 Unity、Unreal、Ren'Py、RPG Maker、AliceSoft 等游戏发行结构及常见老游戏数据文件的识别规则。
- 优化游戏名称推断，避免将 `bin`、`x64`、`Win64` 等通用目录名误用为游戏名称。
- 优化扫描结果弹窗的统计、分组、路径信息和勾选交互，移除扫描完成后的重复顶部提示。

## 扫描说明

- 自动推荐基于本地启发式规则，不代表程序一定是游戏；导入前仍可调整勾选结果。
- 建议优先选择游戏库或游戏安装目录。扫描整个磁盘或包含大量普通软件的目录时，推荐结果中可能出现普通应用。

## 升级说明

- v0.2.1 用户可以在应用内检查并安装 v0.2.2 更新。
- v0.2.0 及更早版本尚未集成更新功能，需要从 GitHub Releases 手动下载安装 v0.2.2。
- 覆盖安装和应用内更新不会删除现有游戏库数据。

## 下载

请从项目的 [GitHub Releases](https://github.com/mpasdi/game-shift/releases) 下载：

```text
Game Shift_0.2.2_x64-setup.exe
```

## 安全说明

- 更新安装包使用 Tauri Updater 签名校验，应用只内置公钥，不包含签名私钥。
- Updater 签名不等同于 Windows Authenticode 代码签名。
- 当前安装包未购买商业代码签名证书，Windows SmartScreen 仍可能显示“未知发布者”提示。

## 系统要求

- Windows 10 / 11。
- x64 处理器与操作系统。
- Microsoft Edge WebView2 Runtime。
