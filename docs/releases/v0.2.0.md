# Game Shift v0.2.0

发布日期：2026-07-28  
版本状态：Beta  
发布渠道：GitHub Releases

Game Shift v0.2.0 聚焦游戏封面管理，在保留本地优先和离线可用的基础上，新增可选的 SteamGridDB 联网封面搜索、选择与本地缓存能力。

## 主要更新

### 封面管理

- 区分游戏图标与游戏封面，在列表和卡片中使用更适合对应场景的视觉资源。
- 自动发现游戏目录中的本地封面。
- 支持在新增和编辑游戏时选择、预览和替换本地封面。
- 统一图片处理流程，按文件内容识别 PNG、JPEG 和 WebP。
- 应用图片方向信息，限制文件大小、图片尺寸和总像素，并将封面重新编码到本地缓存。
- 更换封面后清理已经失效的旧缓存文件。
- 优化无封面时的卡片占位和封面加载状态。

### SteamGridDB 联网封面

- 设置页新增默认关闭的联网封面开关。
- 支持保存、测试和删除用户自己的 SteamGridDB API Key。
- 根据游戏名称搜索 SteamGridDB 游戏条目和竖版静态封面。
- 自动展示最佳匹配，并允许通过下拉列表切换其他游戏结果。
- 支持预览并手动确认封面，不会自动采用第一张候选。
- 保存游戏时重新确认可信资源、下载原图、校验并写入本地缓存。
- 无结果、断网、超时、限流、无效 Key 或图片损坏时提供明确反馈，并保留本地封面选择能力。

### 交互与稳定性

- 优化新增和编辑游戏弹窗的封面入口及表单布局。
- 搜索栏、匹配游戏和封面候选采用独立布局，封面较多时仅滚动候选区域。
- 搜索和切换匹配游戏时增加请求失效保护，避免旧响应覆盖当前结果。
- 保存封面失败时回退新缓存，不覆盖原封面，不遗留不完整文件。
- 补充 Provider、下载限制、配置状态、图片解码和封面保存回退测试。

## 联网与隐私说明

- 联网封面默认关闭，不影响本地游戏管理和启动。
- SteamGridDB API Key 只保存在用户本机，不写入应用源码或安装包。
- 只有用户主动搜索时，搜索词和 API Key 才会发送给 SteamGridDB。
- 本地游戏路径和游戏库数据不会发送给 SteamGridDB。
- Game Shift 不请求或保存 Steam 密码、Steam Guard 验证码等登录凭据。
- 下载仅允许 HTTPS 和受信任的 SteamGridDB 域名，并限制重定向、超时和响应体大小。
- 已缓存到本地的联网封面在关闭联网功能后仍可继续使用。

## 使用联网封面

1. 打开设置页并启用“联网封面”。
2. 登录 SteamGridDB，自行获取并保存 API Key。
3. 测试连接，确认配置状态可用。
4. 新增或编辑游戏，点击封面下方的“联网”按钮。
5. 确认匹配的游戏条目，选择一张封面并保存游戏。

## 安全说明

当前版本未购买商业 Windows 代码签名证书，安装时可能出现“未知发布者”或 Windows SmartScreen 提示。

安装前请确认：

1. 安装包来自项目官方 GitHub Releases。
2. 文件名和版本号与发布页面一致。
3. 本地计算的 SHA-256 与发布页面提供的校验文件一致。

```powershell
Get-FileHash -LiteralPath '.\Game Shift_0.2.0_x64-setup.exe' -Algorithm SHA256
```

## 升级说明

- 可以直接安装 v0.2.0 覆盖旧版本。
- 现有游戏库、收藏、启动记录和本地封面会继续保留。
- 联网封面默认关闭；只有主动启用并配置 SteamGridDB API Key 后才会发起联网请求。
- 升级或卸载前如需额外保护游戏库，可先备份设置页显示的数据库文件。

## 已知限制

- 当前仅提供 Windows x64 安装包。
- 安装包暂未进行商业 Windows 代码签名。
- 联网封面依赖 SteamGridDB 服务和用户自行申请的 API Key。
- 暂不在目录扫描时批量匹配封面，也不会在后台静默替换已有封面。
- 暂不跟踪游戏进程运行状态。
- 暂不统计单次或累计游玩时长。
- 暂不提供自动更新。
- 分类与标签功能尚未开放。
