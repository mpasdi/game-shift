# Game Shift v0.3.0

发布日期：待发布

版本状态：Beta

发布渠道：GitHub Releases

Game Shift v0.3.0 新增游戏运行状态跟踪，在游戏运行期间展示状态并防止重复启动，同时完善运行中的编辑和移除限制，修复部分 Ren'Py 游戏的启动兼容性问题。

## 主要更新

### 游戏运行状态

- 跟踪本次 Game Shift 会话直接启动的游戏进程。
- 首页、全部游戏、收藏和最近游玩视图同步展示运行状态。
- 运行中的启动按钮改为绿色状态标识，并禁止重复启动。
- 检测到游戏退出后恢复启动入口。
- 状态查询暂时失败时保留上次状态并提示，后续同步成功后自动恢复。

### 运行期间的操作限制

- 允许继续修改游戏名称、封面和收藏。
- 锁定可执行文件、工作目录和启动参数，避免更换游戏后沿用旧进程的运行状态。
- 禁止移除运行中的游戏记录，游戏退出后恢复操作。
- 编辑弹窗在可执行文件标签旁显示锁定提示。
- 前后端共同校验，处理编辑、保存和启动同时发生的情况。

### 修复与稳定性

- 修复 Windows 路径规范化产生的扩展路径前缀导致部分 Ren'Py 游戏启动失败的问题，同时保留启动前的路径校验。
- 补充运行状态、重复启动、退出恢复、编辑和移除限制等回归测试。
- 扩充联网封面、应用更新和时间显示等已有核心流程的自动化测试。

## 运行状态的跟踪范围

- 仅跟踪本次 Game Shift 会话直接启动并持有进程句柄的程序，不自动识别从外部启动的游戏。
- 如果启动的是启动器，启动器退出后，其继续运行的子进程不在本版跟踪范围内，启动按钮可能提前恢复。
- 关闭 Game Shift 不会主动关闭游戏；重新打开 Game Shift 后不会接管此前已启动的游戏，也不会继续阻止这些旧进程对应游戏的启动。
- 运行状态不持久化到数据库；仅重载界面而后端仍在运行时，会重新同步当前后端会话中的状态。
- 本版暂不统计单次或累计游玩时长，也不提供关闭游戏进程的操作。

## 升级说明

- v0.2.1 至 v0.2.3 用户可在本版发布后通过应用内更新安装 v0.3.0。
- v0.2.0 及更早版本需要从 GitHub Releases 手动下载安装。
- 覆盖安装和应用内更新保留现有游戏库、收藏、启动记录和本地封面。
- 升级前如需额外保护游戏库，可备份设置页显示的数据库文件。

## 安全说明

- 更新安装包使用 Tauri Updater 签名校验，应用只内置公钥，不包含签名私钥。
- Updater 签名不等同于 Windows Authenticode 代码签名。
- 当前安装包未购买商业代码签名证书，Windows SmartScreen 仍可能显示“未知发布者”提示。

## 系统要求

- Windows 10 / 11。
- x64 处理器与操作系统。
- Microsoft Edge WebView2 Runtime。
