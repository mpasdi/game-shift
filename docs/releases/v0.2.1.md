# Game Shift v0.2.1

发布日期：待发布  
版本状态：Beta  
发布渠道：GitHub Releases

Game Shift v0.2.1 新增应用内更新能力，后续版本可以直接在应用中检查、下载并安装。

## 主要更新

- 应用启动并完成游戏库加载后自动检查一次更新，可在设置页关闭。
- 设置页新增“检查更新”入口，不受自动检查开关影响。
- 发现新版本时展示版本号、发布日期和更新说明。
- 用户确认后才会下载和安装，不进行静默或强制更新。
- 更新失败时支持重试或前往 GitHub Releases 手动下载。

## 升级说明

- v0.2.0 及更早版本尚未集成更新功能，需要手动下载安装 v0.2.1。
- 从 v0.2.1 开始，后续版本可以通过应用内更新完成升级。
- 覆盖安装和应用内更新不会删除现有游戏库数据。

## 下载

请从项目的 [GitHub Releases](https://github.com/mpasdi/game-shift/releases) 下载：

```text
Game Shift_0.2.1_x64-setup.exe
```

## 安全说明

- 更新安装包使用 Tauri Updater 签名校验，应用只内置公钥，不包含签名私钥。
- Updater 签名不等同于 Windows Authenticode 代码签名。
- 当前安装包未购买商业代码签名证书，Windows SmartScreen 仍可能显示“未知发布者”提示。

## 系统要求

- Windows 10 / 11。
- x64 处理器与操作系统。
- Microsoft Edge WebView2 Runtime。
